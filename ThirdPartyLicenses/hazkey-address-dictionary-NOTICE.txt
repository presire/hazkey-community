hazkey-address-dictionary
=========================

The address dictionary (AddressDictionary/, installed as
/usr/share/hazkey-community/AddressDictionary) and its source data
(data/address_entries.tsv) are provided by:

  https://github.com/presire/hazkey-address-dictionary
  Copyright (c) hazkey-community contributors

Data source:
  Japan Post (日本郵便) postal code data (utf_ken_all.zip, UTF-8 edition)
  https://www.post.japanpost.jp/service/search/zipcode/download/utf/utf_ken_all.zip
  Japan Post does not claim copyright in the postal code data and permits
  free redistribution.
