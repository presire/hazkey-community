azooKey emoji dictionary (emoji_all_E17.0.txt)
==============================================

The emoji dictionary file emoji_all_E17.0.txt, installed as
/usr/share/hazkey-community/emoji_all_E17.0.txt, is generated by the
azooKey_emoji_dictionary_storage project:

  https://github.com/azooKey/azooKey_emoji_dictionary_storage

The generated data is derived from the following sources:

1. Unicode emoji data files
     emoji-sequences.txt, emoji-zwj-sequences.txt, emoji-test.txt (Emoji 17.0)
